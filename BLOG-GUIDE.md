# Octi Flow blog

Articles promote Octi Flow. EvaMariaDreams remains the author and publisher.

## Publish an article

1. Copy `src/content/blog/article-template.md`.
2. Rename the copy to the final lowercase slug, for example
   `how-to-remember-to-drink-water.md`.
3. Replace the template text and frontmatter.
4. Keep `draft: true` while editing.
5. Run `npm run check` and `npm run build`.
6. Change to `draft: false` only when the article is ready.

The filename becomes the public URL:

```text
src/content/blog/how-to-remember-to-drink-water.md
https://evamariadreams.com/blog/how-to-remember-to-drink-water.html
```

Do not rename a published file without creating a redirect from the old URL.

## Article fields

- `title`: 10–70 characters.
- `description`: 50–160 characters.
- `publishDate`: first publication date.
- `updatedDate`: only update after a meaningful revision.
- `category`: one stable editorial topic.
- `tags`: internal content labels; no tag pages are generated.
- `image`: site-root URL such as `/assets/img/blog/article/cover.webp`.
- `imageAlt`: required whenever `image` is present.
- `featured`: makes the article the main blog card.
- `draft`: draft and future-dated posts are excluded from HTML, sitemap, and RSS.
- `related`: filenames without `.md`, in deliberate display order.

## Images

Prepare one social/cover image at 1600 × 900 or 1200 × 675. Put article images
under:

```text
public/assets/img/blog/<article-slug>/
```

Use descriptive lowercase filenames and write useful alt text. Decorative
images should use empty alt text in custom MDX components.

## Editorial rules

- Answer the search intent early.
- Prefer a narrow useful article over a broad generic one.
- Cite primary, authoritative sources for health or numeric claims.
- Avoid diagnosis, treatment advice, and guarantees.
- Add internal links only when they help the reader.
- Use one H1 (the template creates it); start article headings at H2.
- Do not publish unedited AI output.

## Routes generated

- `/blog.html`
- `/blog/<slug>.html`
- `/rss.xml`
- `/sitemap-index.xml` and sitemap files generated by the integration

The existing `.html` URL format is preserved by `build.format: "file"`.
